# 100 Hardcoded Accounts

Aplikasi memiliki 100 akun hardcoded di server: `tokoclip001` sampai `tokoclip100`.

Password plaintext **tidak** disimpan di source project. Source hanya berisi SHA-256 dari password unik yang dibuat untuk setiap akun. Daftar username/password lengkap diberikan sebagai file terpisah `tokoclip-100-accounts-OWNER-ONLY.csv`.

Jangan commit/upload file CSV tersebut ke GitHub atau Vercel.
